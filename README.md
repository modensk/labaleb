# Лабалеб Футбол

Своя футбольная карьера для телефона. Пока что база: 50 лиг, команды, стартовые составы и скамейка.

- `scraper/` — парсер. Берёт текущие составы с английской Википедии, возраст и рост с Викиданных, фото игроков только со свободной лицензией.
- `data/` — собранная база (обновляется GitHub Actions каждый понедельник или вручную через «Run workflow»).
- `web/` — приложение.

Данные: Wikipedia / Wikidata, CC BY-SA. Автор и лицензия каждого фото сохранены в карточке игрока.
